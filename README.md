# L2 Warehouse

**Lineage 2 Clan Item Management System** — A modern web application for tracking and managing shared items and within a clan.

## Features

- **Dashboard** — Centralized view of all items, characters, and their assignments
- **Item Management** — Add, edit, and delete items with status tracking (`in_bank` | `assigned` | `borrowed`)
- **Character Management** — Manage clan members and their characters
- **Smart Ownership** — Support for both personal (user-owned) and clan-owned items
- **Transfer Logs** — Full audit trail of item transfers and reassignments
- **Role-Based Access** — Admin and member roles with appropriate permissions
- **Real-time Updates** — Powered by TanStack Query for instant UI sync
